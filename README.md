# LeatherCAD V0.4 CN — UI/UX 完善版

本版重点不是继续堆算法，而是把整个 MVP 整理成更接近可交付软件的操作流程。

## 主流程
**导入照片 → 标定检查 → 分割确认 → CAD 检查 → 导出**

用户不需要理解 HSV、Lab、腐蚀/膨胀等图像参数。

## 本版主要完善
- 重新设计三栏工业/CAD 工作台界面。
- 左侧只负责流程；顶部 Tab 只负责结果查看，避免重复导航。
- 每一步有明确“确认，下一步”。
- 分割页：
  - 自动传统视觉分割
  - 增加目标 / 删除背景
  - 画笔尺寸与圆形光标
  - A/E 快捷键
  - Ctrl+Z 撤销
  - 恢复自动结果
- CAD 页：
  - 最终实体 / 叠加对比 / 原始轮廓 / 节点编辑
  - LINE / ARC / CIRCLE / SLOT
  - 点击实体显示长度、半径、圆心等属性
  - 总宽、总高直接显示在画布
  - 拟合容差可调整并重新拟合
- 导出检查：
  - 轮廓闭合
  - 标定有效
  - CAD 几何
  - mm 单位
- 错误/状态信息重新整理。
- 保留 DXF R2010 真几何实体输出。
- 安装仍默认清华 TUNA 国内 PyPI 镜像。

## V0.4.1 Windows 安装脚本修复

V0.4 的 Windows BAT 使用了带中文的 UTF-8 脚本，在部分中文 Windows / PowerShell 环境中，
CMD 会在 `chcp 65001` 生效前按系统代码页解析文件，从而出现 `锘縖`、变量名被截断、
`不是内部或外部命令` 等错误。

V0.4.1 已彻底修复：
- 三个 `.bat` 文件改为纯 ASCII；
- 使用 Windows CRLF 换行；
- BAT 内不再依赖中文编码或 UTF-8 BOM；
- 不再依赖 `activate.bat`，直接调用 `.venv\Scripts\python.exe`；
- pip 每条安装命令都显式指定清华 TUNA 镜像；
- 可在 PowerShell 或 CMD 中运行。

推荐：
1. 解压到普通目录，例如 `D:\LeatherCAD`。
2. PowerShell 执行 `./install_windows_cn.bat`，或资源管理器双击。
3. 成功后运行 `./start_windows.bat`。


## V0.5：点一下自动选择整块区域

分割修正现在分成两类工具：

- `点选增加`：在漏掉的工件区域点一下，程序根据点击点附近的 Lab 颜色/纹理统计、连通性和 GrabCut 兜底，自动扩展到整块连续区域并加入目标。
- `点选删除`：在误识别背景区域点一下，自动找到与该点属于同一连续视觉区域的部分并整体删除。
- `画笔增加 / 画笔删除`：只用于边缘、缝线附近、低对比或自动区域选择不理想时的精细修正。

算法不是简单的“魔棒固定颜色阈值”。它先对点击点周围取局部中值颜色，估计局部纹理离散程度，自适应生成 Lab 色差阈值，再限制为包含点击点的连通区域；如果区域过小，则使用 OpenCV GrabCut 结合当前 Mask 和点击点进行二次扩展。

针对现有三类真实数据：
1. 米色/橙色材料与深色背景：点选通常可以直接扩展大片材料。
2. 深灰材料与灰地面：颜色接近时可能需要多点一次，或用画笔收边。
3. 缝线、包边和双色材料：允许连续点选多个属于同一工件的区域，最终合并成一个目标 Mask。

快捷键：
- `1` 点选增加
- `2` 点选删除
- `A` 画笔增加
- `E` 画笔删除


## V0.6：真实照片回归后重写几何拟合

本版不是只改参数，而是用现有 3 张真实照片实际跑了完整的“标定→自动分割→轮廓→CAD拟合”回归。

V0.5 的主要问题已确认：旧算法每次最多只向后检查约 28 个轮廓点，因此即使一条物理直边很长，也会被算法人为切成很多 LINE/ARC；同时 1–3 mm 的容差相对于当前约 10 mm 的产品目标过于敏感，会把皮革边缘纹理、包边起伏和分割锯齿当成真实 CAD 几何。

V0.6 改为全局动态规划拟合：允许一整段长边直接竞争成为一个 LINE/ARC，并以“实体数量最少 + 残差受控”为目标。默认拟合容差改为 8 mm，更符合当前约 1 cm 的最终尺寸目标。

自动分割未人工修正情况下的回归统计：
1000048864.jpg: raw_vertices=357, holes=50, outer_entities=66, counts={'LINE': 76, 'ARC': 54, 'CIRCLE': 29, 'SLOT': 0}
1000048862.jpg: raw_vertices=371, holes=7, outer_entities=52, counts={'LINE': 33, 'ARC': 21, 'CIRCLE': 6, 'SLOT': 0}
1000048860.jpg: raw_vertices=4, holes=17, outer_entities=4, counts={'LINE': 17, 'ARC': 9, 'CIRCLE': 12, 'SLOT': 0}

注意：前两张照片的自动 Mask 本身仍混入部分背景/包边噪声，因此这些数字不能视为最终人工确认后的 CAD 质量。V0.6 的重点是消除“算法自己把一条边硬切成很多小段”的结构性问题。人工修正 Mask 后会明显更好。


## V0.7：真实图片对比后的第二轮几何优化

本版针对真实照片回归中暴露出的两个问题继续修改：

1. **自动分割更强烈排斥与整张图边界相连的背景大块**。此前第一张米色工件图会错误选择深色底垫作为主外轮廓，原因是背景面积过大、原评分对触边惩罚不够。V0.7 对触及 2～4 个图像边界的大连通域施加强惩罚。
2. **ARC 判定明显收紧**。圆弧不再仅凭“点到某个圆的残差较小”就接受，还必须满足：
   - 轮廓点绕圆心的角度变化基本单调；
   - 实际轮廓长度与拟合圆弧长度一致；
   - 圆弧跨度 10°～190°；
   - 具有足够弓高，近似直线的曲线优先变成 LINE；
   - ARC 相比 LINE 有额外复杂度惩罚。

目标是恢复“设计几何”，而不是复制皮革边缘的轻微波动。


## V0.8：几何拟合继续优化

这一版继续围绕“不要把一整条边切成很多小段”优化，主要做了：

- LINE 优先：如果一段轮廓在误差允许范围内可以由一条直线解释，就不轻易换成 ARC。
- ARC 更严格：必须满足角度单调、弧长一致、残差受控、弓高足够，避免大半径假圆弧。
- 全局最少实体：仍使用全局动态规划，不限制 28 个点的小窗口。
- 增加三档拟合预设：
  - `细节保留`：4 mm
  - `标准`：8 mm
  - `版型规整`：12 mm
- 允许自定义 0.3～15 mm 容差。

实际在橙色实拍件上测试，使用同一条提取轮廓：
- 6 mm：约 48 个外轮廓实体
- 8 mm：约 31 个
- 10 mm：约 28 个
- 12 mm：约 24 个
- 15 mm：约 24 个

对于当前“约 1 cm 级最终尺寸误差”的目标，默认仍推荐 8 mm；
如果更关注恢复规则版型而不是保留软材料细小起伏，可切到 12 mm 的“版型规整”。

同时需要强调：如果分割 Mask 本身把背景长条、包边外部结构等连到了工件上，
几何拟合层不能安全地把这些错误自动删除，否则可能误删真实结构。
因此 V0.8 仍保留“点选删除整块背景 / 点选增加整块目标”，先把 Mask 修正确，再做 CAD 规则化。


## V0.9：从“轮廓拟合”进入“设计几何恢复”

本版在 V0.8 的全局 LINE/ARC 拟合之后，再增加一层保守的“设计几何规则化”。

### 新增规则
- 近似平行的长直边：归并到同一方向。
- 接近水平/垂直的边：自动吸附到 0° / 90°。
- 接近正交的两组边：自动恢复精确 90°。
- 相邻 LINE-LINE：如果交点离原连接点很近，自动延伸/裁剪到同一交点，避免小断口。
- 多个接近相同半径的 ARC/CIRCLE：在 2 mm 范围内优先归一为同一半径。
- 已经非常接近常见标准半径（R5、R8、R10、R12、R15、R20、R25、R30、R40、R50 等）的圆弧/圆：保守吸附到标准 R。

### 操作
右侧新增：
`设计几何规则化`
默认开启。

如果用户希望完全忠实于拍摄轮廓，可关闭后重新拟合。

### 原则
这一层不会凭空创造复杂结构，只对已经非常接近“直、平行、正交、同半径”的实体做微调。
它的目标是把软材料的轻微摆放变形和边缘波动还原成更接近原始版型的 CAD。


## V0.10：真实照片“点一下整块删除/增加”专项回归

本版专门针对三张原始实拍照片测试点击区域修正，而不是用生成图代替真实数据。

点击区域算法升级为：
1. 点击点周围 15×15 邻域估计材料代表色，避免单像素落在缝线/高光上；
2. Lab 色差中降低亮度权重，提高对光照变化的容忍；
3. Sobel 强边缘作为区域泄漏屏障；
4. 形态学闭运算跨过皮革纹理/缝线造成的小裂缝；
5. 只保留包含点击点的连通区域；
6. 选择异常过小/过大时使用 GrabCut 二次细化；
7. 删除背景和增加目标均按“整块连续视觉区域”工作，画笔只作为兜底。

测试输出位于开发回归目录 leathercad_v010_click_tests（未打入正式运行 workspace）。


## V0.10.1：点选删除改为“Mask 连通块优先”

真实照片测试发现，仅依靠颜色区域生长，在带菱形纹理的深色背景上可能只能选中背景的一小块。
但实际软件中的“点选删除”有一个更可靠的信息：用户点击的是**当前 Mask 中被误加入的区域**。

因此现在删除逻辑优先：
1. 检查点击位置是否已经属于当前目标 Mask；
2. 找出当前 Mask 内包含点击点的完整连通块；
3. 如果它是独立误识别块，一次点击直接整块删除；
4. 只有当误识别背景已经和真实工件粘连成同一大连通块时，才退回 Lab + 边缘 + GrabCut 分割；
5. 删除操作严格限制在当前 Mask 内，不会误删原本未选中的区域。

这比单纯的“魔棒颜色选择”更符合本软件的人工修正语义。


## V0.11：固定拍摄背景方向专项优化

这版把自动分割改成“背景建模优先”，适配后续实际拍摄时主动提高工件/背景对比度的方案。

### 自动分割
- 透视展开后先生成“真实照片有效区域”，排除 warpPerspective 产生的黑色三角区。
- 从真实照片有效边缘采样背景，不再把黑色填充区当背景。
- 在 Lab 空间建立鲁棒背景分布，计算每个像素与背景的马氏距离。
- 与 SAT / CHROMA / DARK / LIGHT 多候选共同评分。
- 候选如果粘到真实图像边界，会被明显降权。
- ArUco 排除区升级：按 1–4、5–8、9–12、13–16 分组，直接遮掉整张 A4 的区域和页边安全余量，不再只遮黑色 Marker。

### 一键删除
仍保持 V0.10.1 的“当前 Mask 连通块优先”：
独立误识别块点一下整块删除；与目标粘连时才进入 Lab + 边缘 + GrabCut。

### 自动回归测试
新增 `regression_real_photos.py`，可以直接对真实 JPG 文件夹运行。
测试包括 ArUco 数量、自动 Mask、亮/暗/对比度/轻微模糊扰动稳定性，以及注入假背景块后的“一键删除”保留率。


## V0.11.1 实拍回归结论

使用现有三张原始实拍照片重新执行自动化测试。所有照片均检测到 16/16 个 ArUco。

对原始照片先施加亮度、变暗、对比度、轻微模糊，再重新执行 ArUco → 透视展开 → A4 排除 → 自动分割。亮度/变暗/对比度三类扰动整体稳定；目前主要弱项是模糊，尤其米色/橙色纹理件。

另外，对每张图的 Mask 人工注入一个独立“错误背景块”，再在该块内部执行一次“点选删除”。三张图均达到：
- 错误块删除率：100%
- 原目标保留率：100%

这验证了 V0.10.1 开始采用的“Mask 连通块优先删除”在独立误识别块场景下是确定性的，不再依赖颜色猜测。

详细机器可读结果见 `REAL_PHOTO_REGRESSION.json`。

## V0.13：标定/形变根因修复
V0.12 的形变根因已定位：使用单个 70 mm ArUco 的四个角直接建立整幅约 1 m 平面的单应矩阵，
微小角点误差被远距离外推放大。V0.13 改为：
- 每张 A4 使用其 4 个 Marker 的已知打印坐标拟合 page→image 单应；
- 多张自由摆放 A4 共同估计同一个平面的无穷远线；
- 使用全部 Marker 的正交/等边约束完成 metric upgrade；
- 使用全部 Marker 边长中位数确定 mm 比例；
- A4 排除区由已知 210×297 mm 页边界反投影得到，不再用 Marker 凸包+25mm 粗暴膨胀。

## V0.14 审核修正
本版是在逐张查看输出图后继续修改的审核版：
- 修复 V0.12 单 Marker 外推导致的大范围透视形变；
- 四张自由摆放 A4 联合 bundle calibration，并自动剔除不共面/异常标定页；
- 第一张自动识别为两个接触工件，默认选择面积最大的主工件；
- A4 区域不再直接从目标 Mask 中硬挖掉，避免纸张靠近/轻微覆盖目标时产生奇怪缺口；
- CAD 阶段增加约 7 mm 级毛刺/包边伪影清理；
- ARC 半径/跨度判定收紧，禁用默认几何方向吸附，优先保证闭合拓扑；
- 默认拟合容差 10 mm，与当前约 1 cm 的产品目标一致。

## V0.16：轮廓/CAD 几何优先版
撤回 V0.15 的强制标定验收路线，恢复 V0.14 的轻量标定流程。本版把主要工作放在“像人工制图一样恢复轮廓”：
- 轮廓等距重采样 + 平滑；
- 用约 20 mm 基线检测持久设计拐角，抑制纹理/包边造成的小拐点；
- 真正拐角之间优先拟合一个完整 LINE，其次一个 ARC；
- 只有单一 LINE/ARC 无法解释时才递归拆段；
- 共线邻边再次合并，减少“一条直边被拆很多段”；
- CAD 实体直接标注长度、角度、R 半径、Ø 直径；
- 双击尺寸标注可修改，后端同步实体 JSON 和 DXF。
测试：`python -m pytest tests -q`

## V0.16.3 圆角保持修复
本版针对真实三张测试图逐图查看后连续迭代：
1. 修复“高曲率=设计拐点”错误，圆角不再被拐点检测切碎后拉成弦线。
2. 改为“长直线区域识别 + 中间曲线连接区拟合”的分解方式。
3. 曲率判断采用更大的物理观察尺度，避免 R40/R60 等圆角在局部窗口内被误判成直线。
4. 曲线连接区允许 15°–220° ARC，可保留四分之一圆、半圆凹口及较大圆角。
5. 新增圆角不可退化为弦线、半圆凹口必须保留 ARC 等回归测试。
当前自动测试：11 项。

## V0.18 工件规则化与多零件分离
- 目标从“忠实描边”进一步调整为“在误差约束内恢复规整制造几何”。
- CAD 提取阶段增加约 10 mm 尺度的稳健边界去毛刺，仅作用于 CAD，不修改用户确认的原始 Mask。
- 连续 LINE/ARC 小链若整体位于约 3–4 mm 直线带内，会合并成单条 LINE。
- 小毛刺夹在两条强设计直线之间时，优先恢复两直线真实交点；明确的大圆角不会删除。
- 自动多尺度侵蚀检测轻微接触的多个工件；真实测试中米色图自动识别为 2 个零件，橙色和灰色保持 1 个。
- 分割页新增“选择零件(0)”：多零件照片中点击某个工件即可单独进入 CAD 拟合，避免接触位置被误画成一个连接结构。

## V0.19 控制点拖拽编辑
CAD 页新增“控制点编辑”：
- LINE：蓝色起点/终点；
- ARC：蓝色端点、黄色圆心、粉色半径柄；
- CIRCLE：黄色圆心、粉色半径柄。
